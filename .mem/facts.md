## project
- architecture — macOS is a native SwiftUI app: the DotsHarness executable composes DotsHarnessUI with DotsHarnessCore; the core owns provider requests, fallback routing, conversation storage and optional loopback gateway. UI copy is resolved by AppCopy in DotsHarnessCore. Release packaging ships English and Turkish resources and splits other locale packs for hash-verified download. Sources: macos/DotsHarness/README.md, Package.swift, Sources/DotsHarnessCore/AppLocalization.swift, scripts/package-dmg.sh.
- constraints — Analiz kapsamı güvenilirlik, güvenlik, bakım ve test riskleridir; kullanıcı bu yanıtında ek sert kısıt belirtmedi.
- conventions — macOS localized copy lives in Sources/DotsHarnessCore/Resources/<language>.lproj/Localizable.strings; en is the SwiftPM default and code uses AppCopy.text/format. Keep all 30 language files aligned with en and preserve format placeholders such as %@. Localization regression tests belong in Tests/HarnessPluginKitTests/LocalizationTests.swift; release packaging hashes non-en/tr string packs. Sources: Package.swift, AppLocalization.swift, LocalizationTests.swift, scripts/package-dmg.sh.
- design-system — No dedicated theme/style/palette file was found in DotsHarnessUI. The SwiftUI shell uses system typography, SF Symbols and semantic dynamic colors (for example Color.primary/secondary and the native window background); preserve these native patterns rather than introducing new styling. Source: macos/DotsHarness/Sources/DotsHarnessUI/AppRailView.swift; checked DotsHarnessUI for theme/style/color/palette files.
- goal — Kullanıcının belirttiği bu çalışma için amaç, tüm depoda genel kod sağlığı analizi yapmak; güvenilirlik, güvenlik, bakım ve test risklerini değerlendirmek.
- out-of-scope — Kullanıcı henüz analiz dışında bırakılmasını istediği bir modül, platform veya konu belirtmedi.
