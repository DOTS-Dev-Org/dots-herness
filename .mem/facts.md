## project
- constraints — Projenin en önemli kısıtı platformlar arası uyumluluktur.
- goal — Bu proje masaüstü ve mobil uygulama olarak kullanılıyor.
- out-of-scope — Tasarım değişiklikleri bu projenin kapsamı dışındadır.
- architecture — macOS app is a Swift Package: DotsHarness executable composes DotsHarnessUI over DotsHarnessCore; RootView renders NavigationSplitView/ConversationView and AppModel coordinates state. AgentBridge is a UI-facing facade over @Observable NativeAgentHost; the host owns conversation/run state and streams provider deltas to UI, with ConversationStore persistence. Sources: macos/DotsHarness/Package.swift, Sources/DotsHarnessUI/RootView.swift, Sources/DotsHarnessUI/ConversationView.swift, Sources/DotsHarnessCore/AppModel.swift, Sources/DotsHarnessCore/AgentBridge.swift, Sources/DotsHarnessCore/AgentBridgeFacade.swift.
- conventions — macOS uses Swift 6 package targets and domain-split Swift files (AppModel+..., AgentBridge+...); UI is SwiftUI and core models/host use Observation with main-actor isolation for app state. Tests are XCTest in macos/DotsHarness/Tests/HarnessPluginKitTests, imported with @testable; run from macos/DotsHarness using swift test (package target in Package.swift).
- design-system — No centralized macOS color/spacing token palette was found. UI follows SwiftUI semantic colors (primary/secondary/accentColor and AppKit semantic backgrounds), system text styles, and rounded-card primitives; reusable small components live in SharedUIComponents.swift. Sources: macos/DotsHarness/Sources/DotsHarnessUI/SharedUIComponents.swift, ConversationView.swift, RootView.swift.
