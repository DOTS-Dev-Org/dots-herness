# Provider mark sources

The desktop and mobile pickers bundle marks locally so they work offline. The original provider vectors in the macOS resource folder provide the shared raster exports used by Windows, Linux, and iOS.

Some of the original provider vectors are Simple Icons marks. Review its trademark guidance before redistributing or changing those marks: <https://github.com/simple-icons/simple-icons> and <https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md>.
