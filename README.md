# dots-herness

## Workspace scanning

Project maps, file indexes, code graphs and background memory study share one ignore policy.
See [workspace scanning](docs/workspace-scanning.md) for .hernessignore exclusions and
selective .hernessinclude paths.

## Cloud runs

Tasks can run on GitHub Actions in the project's own repository and push their changes to a
branch. See [cloud runs](docs/cloud-runs.md) for setup, credentials and limits.
